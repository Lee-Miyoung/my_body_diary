이 버전의 핵심
1. Google 로그인은 '누구인지' 확인하는 용도입니다.
2. 첫 로그인 시 사용자가 개인 암호를 만듭니다.
3. 브라우저 Web Crypto(AES-GCM)가 일기/사진/생년월일/이름을 사용자 기기에서 암호화합니다.
4. Firebase에는 암호문만 저장됩니다.
5. 같은 기기에서 '자동으로 열기'를 선택하면 비밀번호 대신 기기 안의 비추출 암호키로 자동 잠금 해제합니다.
6. 복구키는 Firebase에 원문으로 저장하지 않습니다.
7. '등록 이메일로 보관'은 사용자의 메일 앱을 열어 본인이 자기 이메일로 직접 보내는 방식입니다. 운영자가 복구키를 거치지 않게 하기 위한 설계입니다.
8. 기존 평문 데이터는 해당 사용자가 처음 개인 암호를 설정할 때 자동으로 암호화 데이터로 변환됩니다.

중요한 한계
- Firebase 프로젝트 관리자는 Authentication의 이메일/UID, 기록 날짜 키, 암호문 크기 같은 메타데이터는 볼 수 있습니다.
- 하지만 일기 내용, 사진, 생년월일, 이름 등 암호화된 내용은 개인 암호/복구키 없이는 읽을 수 없습니다.
- 개인 암호와 복구키, 그리고 같은 기기에 저장된 자동잠금해제 정보까지 모두 잃으면 관리자도 복구할 수 없습니다.
